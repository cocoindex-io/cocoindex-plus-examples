# Examples for CocoIndex Plus

This directory contains examples for CocoIndex Plus.

| Example | Description |
|---------|-------------|
| [GitHub Code Indexing](github_code_indexing) | Index code from a GitHub repository |
| [Multi GitHub Code Indexing](multi_github_code_indexing) | Index code from multiple GitHub repositories based on a refreshing config file|
| [Code Elements Indexing](code_elements_indexing) | Extract and index code declarations and references from a GitHub repository |
| [Multi-Source Knowledge Graph](multi_source_knowledge_graph) | One Neo4j knowledge graph from a Postgres catalog, Markdown docs, and GitHub issues, pull requests, and releases; entity and person nodes are shared components held by every source that knows them |
